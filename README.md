# crushflag

Crush encode/decode helpers for flag payloads in pipelines.

**Site:** https://theworker02.github.io/crushflag/

## Install / run

```bash
git clone https://github.com/theworker02/crushflag.git
cd crushflag
node src/cli.js
node --test
```
